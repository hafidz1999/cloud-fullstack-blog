Cloud Full-Stack Blog — Documentation

Project Overview

This project is a cloud-deployed full-stack blog application built as a final Cloud Engineering project. The application consists of a static frontend and a RESTful backend deployed on Google Cloud Run. It records visitor traffic and displays statistics using a cloud-native database.

The main goal of this project is to demonstrate containerization, serverless deployment, CI/CD automation, and cloud-native monitoring.

Architecture

Browser
  ↓
Frontend (Cloud Run, Nginx)
  ↓ HTTP
Backend API (Cloud Run, Flask)
  ↓
Firestore (NoSQL Database)

The frontend is served as static files using Nginx on Cloud Run. JavaScript in the frontend calls backend REST endpoints to record visits and retrieve statistics. The backend stores visit data in Google Firestore.

CI/CD Pipeline

This project uses GitHub Actions to automate deployments. On every push to the main branch:

  • The backend service is built and deployed to Cloud Run
  • The frontend service is built and deployed to Cloud Run

GitHub Actions authenticates to Google Cloud using a service account stored as a repository secret. This ensures no credentials are committed to the repository.

Monitoring & Logging

Because the application is deployed on Cloud Run, logs and metrics are collected automatically by Google Cloud. A custom Cloud Monitoring dashboard was created to observe:

  • Request count (traffic)
  • Request latency
  • Error rates (5xx responses)

This allows basic operational visibility without installing any monitoring agents.
